# Support

Need help with Artist Alley? Here's where to look.

- **Documentation** — [artist-alley.org/docs](https://artist-alley.org/docs/guides/getting-started) covers install, setup, and day-to-day use.
- **Bugs** — open an issue on [artist-alley](https://github.com/Artist-Alley-Org/artist-alley/issues) with steps to reproduce.
- **Questions and ideas** — start a discussion on the repository's Discussions tab.
- **Security** — see [SECURITY.md](./SECURITY.md); please don't report vulnerabilities in public issues.

We're a small project, so please be patient — but we do read everything.
